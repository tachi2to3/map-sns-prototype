\# 地図ベースSNSプロトタイプ



\## プロジェクト概要

React + Firebase を使った地図ベースのSNSです。  

ユーザーは日常の思い出を場所に紐づけて投稿・閲覧できます。



\## 開発環境

\- Node.js v18 以上

\- React + Vite

\- Tailwind CSS

\- Firebase (Authentication, Firestore, Hosting)



\## セットアップ手順



1\. リポジトリをクローン

https://github.com/tachi2to3/map-sns-prototype

2\. 依存関係をインストール

npm install

3\. 開発サーバーを起動

npm run dev
